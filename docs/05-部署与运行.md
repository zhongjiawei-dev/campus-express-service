# 部署与运行

## 环境

- Python 3.11+
- MariaDB 10.6 或 MySQL 8
- Linux / macOS / Windows 都可以跑

依赖：

```bash
pip install -r requirements.txt
```

`requirements.txt` 只有运行服务需要的 `PyMySQL`；`requirements-dev.txt` 额外包含 pytest、requests、PyYAML，供自测使用。

## 数据库

登录 MariaDB：

```bash
sudo mysql -uroot
```

执行：

```sql
CREATE DATABASE campus_test DEFAULT CHARSET utf8mb4;
CREATE USER 'campus'@'127.0.0.1' IDENTIFIED BY 'Campus@123';
GRANT ALL PRIVILEGES ON campus_test.* TO 'campus'@'127.0.0.1';
FLUSH PRIVILEGES;
```

如果数据库不在本机，改 `DB_HOST` 后重新授权对应地址。

## 启动服务

```bash
python app/server.py --port 9300 --reset
```

参数：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--port` | 9300 | 监听端口 |
| `--reset` | 关闭 | 删表重建并写入种子账号 |

不加 `--reset` 时只执行 `CREATE TABLE IF NOT EXISTS`，不会清空数据。

启动成功会看到：

```
campus express listening on :9300
```

浏览器打开 `http://127.0.0.1:9300/` 进入登录页。页面和接口由同一个进程提供，不需要再启动前端开发服务器。

## 环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `DB_HOST` | `127.0.0.1` | 数据库地址 |
| `DB_PORT` | `3306` | 数据库端口 |
| `DB_USER` | `campus` | 数据库账号 |
| `DB_PASSWORD` | `Campus@123` | 数据库密码 |
| `DB_NAME` | `campus_test` | 数据库名 |
| `QUIET` | 空 | 设为 `1` 关闭访问日志 |

## 健康检查

```bash
curl http://127.0.0.1:9300/api/health
```

返回：

```json
{"code":0,"message":"ok","data":{"status":"up","users":4}}
```

`users` 是当前用户数量，可以用来确认数据库连接正常。

## 种子数据

`--reset` 会写入 4 个账号：

| 角色 | 手机号 | 密码 | 钱包 |
| --- | --- | --- | --- |
| 管理员 | 13800000000 | Admin@123 | 0 |
| 学生 | 13800000001 | Stu@123 | 300.00 |
| 骑手 A | 13800000002 | Run@123 | 50.00 |
| 骑手 B | 13800000003 | Run@456 | 50.00 |

## 用 Postman 调接口

导入 `postman/campus-express.postman_collection.json`。

集合里的请求按文件夹组织：

1. 账号与鉴权：注册、登录、当前用户；
2. 订单：发布、列表、详情、取消；
3. 履约：接单、取件、送达、签收、评价；
4. 钱包与信用：余额、充值、流水、信用分；
5. 存证：时间线、校验；
6. 管理：订单、统计。

先跑“01 账号与鉴权”拿 token，后面的请求通过集合变量传递 `student_token`、`courier_token`、`admin_token`。

## 自测

```bash
pytest
```

自测脚本会自动选一个空闲端口启动服务，使用 `campus_test` 库，跑完关闭服务。数据库需要提前建好，账号密码和上面一致。

只跑某个文件：

```bash
pytest tests/test_lifecycle.py -q
```

## GitHub Actions

`.github/workflows/ci.yml` 在每次 push 时：

1. 启动 MariaDB 10.6 service；
2. 安装 Python 依赖；
3. 等待数据库端口可用；
4. 执行 `pytest`；
5. 上传自测输出。

CI 使用的数据库账号在 workflow 里配置，和本地默认值一致。

## 常见问题

**服务启动报 `Can't connect to MySQL server`**

先确认 MariaDB 正在运行，`DB_HOST`、`DB_PORT` 是否正确。

**`--reset` 后数据没了**

`--reset` 本来就会删表重建，只在需要重置演示数据时使用。

**端口被占用**

换一个端口：`python app/server.py --port 9301 --reset`。

**Postman 返回 401**

检查 `Authorization` 是否是 `Bearer <token>`，token 是否超过 2 小时有效期。
