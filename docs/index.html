Main flow

一条订单从发布到签收

学生、骑手、管理员在同一个工作台里协作

01 / 发布填写代取需求物品、取件点、送达点、跑腿费、超时时间

04 / 送达送到指定地点骑手标记已送达
05 / 签收结算并评价扣跑腿费，生成双方流水，写存证

Implementation

系统怎么实现

浏览器工作台、接口、数据库和存证链

一个进程同时托管页面和接口

ThreadingHTTPServer 直接返回 web/ 下的页面、样式和脚本；/api/... 进入业务路由。前端不需要 Node.js，也不需要单独部署。

订单状态与权限分开判断

学生只能取消、签收、评价自己的订单；骑手只能接单、取件、送达自己接的订单；管理员查看全量订单和统计。

金额、流水、存证一起提交

签收时更新订单、扣下单人余额、给骑手入账、写双方流水，再追加一条哈希存证；任一步失败就回滚。

Run locally

本地运行

需要 Python 3.11+ 和 MariaDB 10.6 / MySQL 8

# 1. 安装依赖
pip install -r requirements.txt

# 2. 初始化表并启动
python app/server.py --port 9300 --reset

# 3. 浏览器打开
http://127.0.0.1:9300/
