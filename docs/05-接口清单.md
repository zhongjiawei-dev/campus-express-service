# 校园快递代取平台 · 接口清单

服务地址默认 `http://127.0.0.1:9300`，所有响应统一为：

```json
{"code": 0, "message": "ok", "data": {}}
```

业务失败时 `code` 非 0，HTTP 状态码同步变化。

## 1. 账号与鉴权

| # | 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | GET | `/api/health` | 否 | 健康检查，返回用户数 |
| 2 | POST | `/api/register` | 否 | 注册，默认学生角色，成功直接返回 token |
| 3 | POST | `/api/login` | 否 | 登录，返回 token 和角色 |
| 4 | GET | `/api/me` | 是 | 当前登录用户 |
| 5 | GET | `/api/users/{id}` | 是 | 用户资料，手机号脱敏 |

## 2. 订单

| # | 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- | --- |
| 6 | GET | `/api/orders` | 是 | 订单列表，支持 `scope=mine/available`、`status`、`page`、`size` |
| 7 | POST | `/api/orders` | 是 | 创建订单 |
| 8 | GET | `/api/orders/{id}` | 是 | 订单详情，含 `expired` |
| 9 | POST | `/api/orders/{id}/take` | 是 | 骑手接单 |
| 10 | POST | `/api/orders/{id}/pickup` | 是 | 骑手取件 |
| 11 | POST | `/api/orders/{id}/deliver` | 是 | 骑手送达 |
| 12 | POST | `/api/orders/{id}/sign` | 是 | 学生签收，触发扣款和转账 |
| 13 | POST | `/api/orders/{id}/cancel` | 是 | 学生取消待接单订单 |
| 14 | POST | `/api/orders/{id}/review` | 是 | 学生评价，加减信用分 |

## 3. 存证

| # | 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- | --- |
| 15 | GET | `/api/orders/{id}/timeline` | 是 | 订单存证时间线 |
| 16 | GET | `/api/orders/{id}/verify` | 是 | 校验哈希链，返回 valid、checked、broken_at |

## 4. 钱包与信用

| # | 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- | --- |
| 17 | GET | `/api/wallet` | 是 | 钱包余额 |
| 18 | POST | `/api/wallet/recharge` | 是 | 充值，1-1000 元 |
| 19 | GET | `/api/flows` | 是 | 流水列表，支持 `type` |
| 20 | GET | `/api/credit` | 是 | 信用分和变动记录 |

## 5. 管理端

| # | 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- | --- |
| 21 | GET | `/api/admin/orders` | 是（admin） | 全部订单，含 expired |
| 22 | GET | `/api/admin/stats` | 是（admin） | 用户数、按状态订单数、流水汇总 |

## 6. 关键参数

### 创建订单

```json
{
  "title": "取快递",
  "pickup": "菜鸟驿站",
  "dropoff": "3栋201",
  "fee": "8.50",
  "timeout_minutes": 30
}
```

| 字段 | 规则 |
| --- | --- |
| title | 2-30 字 |
| pickup | 2-50 字 |
| dropoff | 2-50 字 |
| fee | 1.00-500.00 元，最多两位小数 |
| timeout_minutes | 10-180 的整数，不传默认 60 |

### 评价

```json
{"rating": 5, "comment": "送得挺快"}
```

`rating` 1-5，5 星 +1，4 星不加不减，1-3 星 -1。

## 7. 错误码

| code | HTTP | 含义 |
| --- | --- | --- |
| 0 | 200 | 成功 |
| 40001 | 400 | 请求体不是合法 JSON 对象 |
| 40002 | 400 | 参数格式错误 |
| 40004 | 400 | 参数超出范围 |
| 40101 | 401 | 没带 Token |
| 40102 | 401 | Token 无效或过期 |
| 40103 | 401 | 手机号或密码错误 |
| 40301 | 403 | 没有权限（角色不对或不是本人订单） |
| 40401 | 404 | 订单或接口不存在 |
| 40901 | 409 | 手机号已注册 |
| 40902 | 409 | 当前状态不允许该操作 |
| 40903 | 409 | 钱包余额不足 |
| 40904 | 409 | 订单已超时（接口约定里有，接单接口尚未使用） |
| 50001 | 500 | 服务端异常 |
