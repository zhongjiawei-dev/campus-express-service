# 接口文档

Base URL：`http://127.0.0.1:9300`

所有接口返回 JSON：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

需要登录的接口在请求头带：

```
Authorization: Bearer <token>
```

## 1. 健康检查

`GET /api/health`

不需要登录。

```json
{"code":0,"message":"ok","data":{"status":"up","users":4}}
```

## 2. 注册

`POST /api/register`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `phone` | string | 是 | 11 位手机号 |
| `password` | string | 是 | 至少 6 位 |

```json
{"phone":"13900000001","password":"Test@123"}
```

返回注册用户和 token：

```json
{"code":0,"message":"ok","data":{"phone":"13900000001","token":"...","role":"student"}}
```

## 3. 登录

`POST /api/login`

```json
{"phone":"13800000001","password":"Stu@123"}
```

```json
{"code":0,"message":"ok","data":{"token":"...","role":"student"}}
```

## 4. 当前用户

`GET /api/me`

需要登录。返回 `id`、`phone`、`role`、`credit_score`、`wallet`。

`wallet` 是两位小数的字符串，例如 `"300.00"`。

## 5. 查看用户资料

`GET /api/users/{id}`

需要登录。返回指定用户的公开资料，字段同 `/api/me`。

## 6. 订单列表

`GET /api/orders`

需要登录。查询参数：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `status` | 空 | 按状态筛选 |
| `scope` | `mine` | `mine` 我发布的；`courier` 我接的；`available` 待接单；管理员不传则查全部 |
| `page` | 1 | 页码 |
| `size` | 20 | 每页数量，最大 50 |

返回：

```json
{"code":0,"message":"ok","data":{"items":[],"page":1,"size":20}}
```

## 7. 发布订单

`POST /api/orders`

需要登录，学生或管理员可用。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `title` | string | 是 | 2–30 字 |
| `pickup` | string | 是 | 2–50 字 |
| `dropoff` | string | 是 | 2–50 字 |
| `fee` | number/string | 是 | 1–500 元，最多两位小数 |
| `timeout_minutes` | int | 否 | 10–180，默认 60 |

```json
{
  "title":"取快递",
  "pickup":"菜鸟驿站",
  "dropoff":"3栋201",
  "fee":"8.50",
  "timeout_minutes":30
}
```

返回订单对象，包含 `order_no`、`status`、`fee`、`expired` 等字段。

## 8. 订单详情

`GET /api/orders/{id}`

需要登录。返回订单对象。

## 9. 接单

`POST /api/orders/{id}/take`

需要骑手登录。订单必须是 `pending`，且不能接自己发布的订单。

成功后订单状态变为 `taken`，写入 `taken_at` 和一条存证。

## 10. 取件

`POST /api/orders/{id}/pickup`

需要接单骑手登录。订单必须是 `taken`。

成功后状态变为 `delivering`，写入 `picked_at` 和存证。

## 11. 送达

`POST /api/orders/{id}/deliver`

需要接单骑手登录。订单必须是 `delivering`。

成功后状态变为 `delivered`，写入 `delivered_at` 和存证。

## 12. 签收

`POST /api/orders/{id}/sign`

需要下单学生登录。订单必须是 `delivered`。

签收时：

- 检查学生余额是否足够；
- 学生钱包扣跑腿费；
- 骑手钱包加跑腿费；
- 写学生 `order_pay` 流水和骑手 `order_income` 流水；
- 订单状态改为 `signed`，写 `signed_at` 和存证。

## 13. 取消

`POST /api/orders/{id}/cancel`

需要下单学生登录。订单必须是 `pending`。

成功后状态变为 `cancelled`，写入 `cancelled_at` 和存证。

## 14. 评价

`POST /api/orders/{id}/review`

需要下单学生登录。订单必须是 `signed`。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `rating` | int | 是 | 1–5 |
| `comment` | string | 否 | 最多 100 字 |

评分 4–5 加 1 分，1–2 扣 1 分，3 分不变；变动写 `credit_logs`。

## 15. 存证时间线

`GET /api/orders/{id}/timeline`

需要登录。返回该订单全部存证记录，按 `id` 升序：

```json
{
  "code":0,
  "message":"ok",
  "data":[
    {
      "id":1,
      "event":"created",
      "payload":{"order_no":"CX...","title":"取快递","status":"pending","fee":"8.50"},
      "prev_hash":"000...",
      "record_hash":"...",
      "created_at":"2026-11-19 10:00:00"
    }
  ]
}
```

## 16. 校验存证

`GET /api/orders/{id}/verify`

需要登录。返回：

```json
{"code":0,"message":"ok","data":{"valid":true,"checked":5,"broken_at":null}}
```

如果中间被篡改，`valid` 为 `false`，`broken_at` 是第一条不一致的记录 id。

## 17. 钱包余额

`GET /api/wallet`

需要登录。

```json
{"code":0,"message":"ok","data":{"wallet":"291.50"}}
```

## 18. 充值

`POST /api/wallet/recharge`

需要登录。

```json
{"amount":"100"}
```

金额 1–1000 元，成功后返回新余额，并写一条 `recharge` 流水。

## 19. 钱包流水

`GET /api/flows`

需要登录。可选 `type`：

- `recharge`
- `order_pay`
- `order_income`

返回流水列表，`amount` 为字符串，支出是负数。

## 20. 信用分

`GET /api/credit`

需要登录。

```json
{
  "code":0,
  "message":"ok",
  "data":{
    "credit_score":101,
    "logs":[
      {"change_value":1,"reason":"review","ref":"CX...","created_at":"2026-11-19 10:10:00"}
    ]
  }
}
```

## 21. 管理员查订单

`GET /api/admin/orders`

需要管理员登录。可选 `status` 过滤。

返回 `{"items":[...]}`。

## 22. 管理员统计

`GET /api/admin/stats`

需要管理员登录。

```json
{
  "code":0,
  "message":"ok",
  "data":{
    "users":4,
    "chain_records":12,
    "paid_orders":2,
    "orders_by_status":{
      "pending":{"count":1,"fee":"8.50"},
      "signed":{"count":2,"fee":"17.00"}
    }
  }
}
```

## 错误码

| 错误码 | HTTP | 含义 |
| --- | --- | --- |
| `40001` | 400 | 请求体不是合法 JSON |
| `40002` | 400 | 参数格式不对 |
| `40004` | 400 | 参数超出范围 |
| `40101` | 401 | 未登录 |
| `40102` | 401 | token 格式不对、无效或过期 |
| `40103` | 401 | 手机号或密码错 |
| `40301` | 403 | 没有权限 |
| `40401` | 404 | 资源不存在 |
| `40901` | 409 | 手机号已注册 |
| `40902` | 409 | 当前状态不允许该操作 |
| `40903` | 409 | 余额不足 |
| `50001` | 500 | 服务端异常 |
